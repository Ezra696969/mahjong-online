Kebijakan Privasi

Terakhir diperbarui: 13 Oktober 2026. Halaman ini menjelaskan data apa yang diproses Mahjong Online ("kami") saat kamu bermain, dan apa pilihanmu.

Ringkasnya

  • Tidak ada akun, kata sandi, atau data pembayaran.
  • Kami hanya memakai nama panggilan yang kamu ketik, dan hanya selama ruangan aktif.
  • Pesan chat dan skor tidak disimpan setelah ruangan selesai.

Data yang kami proses

Nama panggilan

Nama yang kamu ketik dikirim ke server dan ditampilkan kepada pemain lain di ruangan yang sama. Nama hanya ada di memori server selama ruangan masih aktif dan hilang saat ruangan dihapus atau server dimulai ulang. Jangan memakai nama asli atau informasi pribadi bila kamu tidak ingin orang lain melihatnya.

Pesan chat

Pesan diteruskan ke pemain di ruangan yang sama dan tidak disimpan oleh server.

Data permainan

Ubin, langkah, dan skor hanya hidup di memori server selama ronde berlangsung dan tidak dikaitkan dengan identitasmu.

Data teknis

Seperti situs web pada umumnya, penyedia hosting dan jaringan penghantar konten yang kami pakai dapat memproses alamat IP dan data teknis permintaan (jenis browser, waktu akses) untuk menjalankan layanan dan menjaga keamanan. Kami sendiri tidak membangun profil pengguna dari data ini.

Penyimpanan di perangkatmu

Game menyimpan sedikit data di browsermu agar berfungsi dengan baik:

  • sessionStorage: kode ruangan dan token sesi, supaya kamu bisa kembali ke kursimu setelah halaman dimuat ulang. Terhapus saat tab ditutup.
  • localStorage: nama terakhir yang kamu pakai, pilihan animasi hidup atau mati, dan penanda bebas iklan bila ada.
  • Cache aplikasi (service worker): salinan file game agar bisa dibuka lebih cepat dan dipasang sebagai aplikasi.

Kami tidak menyetel cookie sendiri. Kamu bisa menghapus semua data ini kapan saja lewat pengaturan browser.

Pihak ketiga

  • Google Fonts: huruf pada beberapa tampilan dimuat dari server Google, sehingga alamat IP dan data browsermu dikirim ke Google. Lihat Kebijakan Privasi Google.
  • Penyedia hosting: server game berjalan di layanan hosting pihak ketiga yang memproses data teknis seperti dijelaskan di atas.

Iklan

Saat ini Mahjong Online belum menampilkan iklan. Bila iklan diaktifkan di kemudian hari, halaman ini akan diperbarui terlebih dahulu. Iklan akan ditaruh di tempat tersendiri yang terpisah dari area bermain, dan pemain bisa memilih opsi bebas iklan bila tersedia.

Bila iklan dari Google AdSense atau mitranya ditampilkan, pihak ketiga tersebut, termasuk Google, dapat memakai cookie atau pengenal perangkat untuk menayangkan iklan berdasarkan kunjunganmu ke situs ini dan situs lain. Kamu dapat mengelola atau menonaktifkan iklan yang dipersonalisasi lewat pengaturan iklan Google, dan mempelajari cara Google memakai data di halaman teknologi iklan Google. Untuk pengunjung di wilayah yang mensyaratkannya (misalnya Wilayah Ekonomi Eropa dan Inggris), kami akan menampilkan permintaan persetujuan sebelum iklan yang dipersonalisasi.

Anak-anak

Layanan ini tidak ditujukan bagi anak di bawah 13 tahun, dan kami tidak dengan sengaja mengumpulkan data pribadi anak. Orang tua yang mengetahui anaknya memberikan data pribadi dapat menghubungi kami agar kami bisa menindaklanjutinya.

Hak dan permintaanmu

Karena kami tidak menyimpan akun atau riwayat, hampir semua data hilang sendiri saat ruangan selesai. Kamu bisa keluar dari ruangan kapan saja (kursimu diganti bot) dan menghapus data di browsermu lewat pengaturan browser. Untuk pertanyaan atau permintaan lain terkait privasi, hubungi kami lewat halaman Issues di GitHub (jangan menuliskan data pribadi di laporan publik).

Perubahan kebijakan

Kebijakan ini dapat diperbarui. Tanggal pembaruan terakhir tertera di bagian atas halaman, dan perubahan penting akan dicantumkan di sini.
